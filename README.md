# PAK INTERIORS — Lahore Atelier

A luxury architectural and bespoke interior design website featuring a 300-frame cinematic scroll walkthrough, curated portfolio gallery, and Supabase integration.

## Features

- **300-Frame Cinematic Walkthrough**: Canvas-rendered smooth scroll sequence with progressive loading.
- **Editorial Design System**: Typography-driven aesthetic using *Cormorant Garamond* and *Plus Jakarta Sans*.
- **Dynamic Portfolio Grid**: Curated residential and commercial projects with modal details.
- **Supabase Backend**: Contact inquiries and consultation booking pipeline.
- **Optimized for Netlify**: Pre-configured caching headers for high-performance asset delivery.

## Local Development

Run using any local HTTP server (such as PowerShell script included):

```powershell
.\server.ps1
```

Or using Python:
```bash
python -m http.server 8000
```

Or using Node:
```bash
npx serve .
```
